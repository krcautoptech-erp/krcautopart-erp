## What DrawSQL does for SQL and databases
- Visual ER diagrams: drag and edit tables and relationships directly on a canvas, no diagram syntax needed.
- Import SQL: paste CREATE TABLE statements (MySQL, PostgreSQL, SQL Server) and get an interactive diagram automatically.
- Export: SQL DDL scripts for MySQL, PostgreSQL or SQL Server, images for documentation, and framework migrations such as Laravel.
- Templates: 200+ real-world schemas from popular apps for inspiration or a quick start.
- AI help: generate tables, rename and review a schema on the diagram.
- Organization: table groups, sticky notes and auto layout to keep large schemas readable.
- Teams: real-time collaboration, discussions, permissions, version history, public links and presentation mode (some features on paid plans).
Features, plans and limits can change, so check DrawSQL's site for current details.

## Workflow
1. Design or fix the schema here and get clean CREATE TABLE statements.
2. Import them into DrawSQL to see the full ER diagram.
3. Arrange, group and refine tables visually; share with the team.
4. Export DDL or migrations and run them on your database.
5. Come back here for queries, indexes, optimization and migrations.
