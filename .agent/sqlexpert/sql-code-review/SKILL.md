1. Review the SQL across: correctness, performance, security, readability and maintainability.
2. List findings by severity (critical, important, nice to have), each with the line, the problem and the fix.
3. Check: SELECT *, implicit joins, non-sargable filters, NULL traps, missing ORDER BY with LIMIT, unsafe dynamic SQL, missing transactions on multi-step writes, magic numbers, unclear aliases.
4. Return a clean rewritten version with consistent formatting: uppercase keywords, one clause per line, leading or trailing commas used consistently, meaningful aliases, CTEs for complex logic.
5. Give a short score out of 10 and the top three improvements.
